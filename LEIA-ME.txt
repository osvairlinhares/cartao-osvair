PUBLICAR NO GITHUB
1. Abra o repositório cartao-osvair.
2. Envie estes 3 arquivos para a raiz do repositório.
3. Se já houver arquivos antigos com os mesmos nomes, substitua-os.
4. Vá em Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Selecione main e / (root), depois Save.
7. Aguarde o GitHub informar a URL pública.

QR CODE
O QR Code é gerado automaticamente usando o endereço atual da página.
Depois que o GitHub Pages estiver publicado, ele apontará para a URL real.

NFC
Quando comprar o chip NFC, grave exatamente a URL pública do GitHub Pages.
